## Before publishing

1. Open `index.html`.
2. Confirm the LinkedIn URL.
3. Add repository links as each project is cleaned and published.
4. Optionally add a professional email address or downloadable resume later.

## Publish with GitHub Pages

1. Create a public GitHub repository. Recommended name: `pancaketoes.github.io`.
2. Upload `index.html` and `styles.css` to the root of the repository.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings**.
5. Select **Pages** under **Code and automation**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)` folder, then click **Save**.
8. After deployment, the portfolio should appear at `https://pancaketoes.github.io/`.
